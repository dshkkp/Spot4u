# Spot4u

Spot4u помогает студентам найти место для учёбы рядом с двумя корпусами Финансового университета в Москве. В каталоге 104 записи: 73 у корпуса на Ленинградском проспекте и 31 у корпуса на Вешняковском проезде. Можно выбрать категорию и удобства, ограничить цену и время в пути, а затем отсортировать места по времени в пути, цене или оценке StudyScore. Результаты доступны списком и на карте в Android, iOS и веб-версии.


## Переходы между экранами

На главном экране выберите корпус и хотя бы одну категорию, затем нажмите «Показать места». Откроется список. Переключитесь на карту, чтобы увидеть те же места рядом с корпусом. Нажмите на карточку в списке или на маркер на карте, чтобы посмотреть подробности и открыть маршрут. Если подходящих мест нет, нажмите «Изменить фильтры».

## Что происходит после выбора условий

Когда вы нажимаете «Показать места», приложение отправляет на сервер выбранный корпус, категории, фильтры и приоритет. Пока идёт поиск, на экране виден индикатор загрузки.

Сначала сервер берёт из каталога места выбранных категорий рядом с вашим корпусом. Затем проверяет каждое место по всем включённым фильтрам. Например, если вы указали Wi-Fi и средний чек до 650 ₽, в результат попадут только места с подтверждённым Wi-Fi и известным чеком не выше 650 ₽. Для условия «Открыто сейчас» сервер сверяет расписание с текущим временем в Москве.

Приоритет задаёт порядок найденных мест. В режиме «Поближе» первыми идут места с самым коротким временем в пути от корпуса, в режиме «Подешевле» — с самым низким средним чеком. В режиме «Сбалансированно» сервер учитывает сразу пять признаков: время в пути, цену, наличие розеток и Wi-Fi, а также рейтинг. Чем выше общая оценка, тем выше место в списке.

Приложение получает отсортированный список и координаты мест. Поэтому при переключении на карту вы видите те же результаты без повторного поиска. Если ни одно место не подходит, приложение предлагает изменить фильтры.

## Запуск и установка

Для локального запуска нужны Docker Compose, Python 3 и Flutter 3.50.1. Из корня проекта выполните:

```bash
docker compose up --build -d
python3 scripts/build_web.py
python3 scripts/serve_preview.py
```

Оставьте терминал открытым и перейдите на [localhost:3000](http://localhost:3000). Docker запускает базу, импортирует обе таблицы Excel и поднимает API. Проверить его можно по адресу [localhost:8000/health](http://localhost:8000/health).

- **Android или iOS:** запустите эмулятор Android или симулятор iOS, затем выполните в папке `mobile/` команды `flutter pub get` и `flutter run`. Для iOS нужен Mac с Xcode.
- **iPhone, веб-версия:** откройте HTTPS-адрес работающего приложения в Safari и выберите «Поделиться» → «На экран Домой».
- **Остановка локальной версии:** нажмите Ctrl+C в терминале веб-сервера и выполните `docker compose down`. Каталог останется в томе базы.
