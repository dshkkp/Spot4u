# Spot4u

**Spot4u** - сервис персонального подбора мест для учёбы и работы. Проект помогает студентам и другим пользователям быстро находить подходящие кафе, кофейни, библиотеки, коворкинги и подобные места по важным для них параметрам.

Основная идея проекта - собрать в одном месте информацию, которая обычно разбросана по разным сервисам: наличие Wi‑Fi и розеток, средний чек, студенческие скидки, пригодность места для работы с ноутбуком, режим работы и другие характеристики.

## Проблема

Обычные картографические сервисы хорошо показывают организации на карте, но не ориентированы на подбор места именно для учёбы или работы.

Пользователю приходится искать разные типы мест по отдельности: сначала кафе, потом коворкинги, библиотеки и другие варианты, каждый раз заново просматривая карточки, отзывы, характеристики и маршруты. Spot4u объединяет все подходящие места в одном сервисе и позволяет сразу искать и сравнивать их по единым критериям.

## Основные возможности

Пользователь сможет:

- указать исходную точку (корпус университета);
- выбрать нужные категории мест;
- задать параметры поиска;
- фильтровать места по Wi‑Fi, розеткам, среднему чеку, студенческой скидке и другим доступным характеристикам;
- получить список подходящих мест;
- увидеть места на карте;
- открыть карточку места;
- получить итоговый **StudyScore** — оценку соответствия места текущему запросу;
- перейти к построению маршрута в картах;
- в дальнейшем оставлять оценки и уточнять характеристики мест.

## StudyScore

После применения обязательных фильтров подходящие места ранжируются по степени соответствия запросу пользователя.

Итоговый `StudyScore` рассчитывается на основе доступных характеристик места и выбранных пользователем критериев.

## Данные

Spot4u использует собственную локальную базу мест в пилотной части Москвы.

Основные источники данных:

- открытые картографические и справочные источники;
- 2ГИС;
- официальные сайты и страницы заведений;
- ручная проверка данных командой;
- в дальнейшем - пользовательские оценки и уточнения.


Основные характеристики места:

- название;
- категория;
- адрес;
- координаты;
- режим работы;
- Wi‑Fi;
- розетки;
- средний чек;
- студенческие скидки;
- пригодность для работы с ноутбуком;
- рейтинг и другие доступные сведения.

Если значение неизвестно, оно хранится как `null` / `unknown`, а не автоматически считается отрицательным.

## Основные технологии и соглашения

На текущем этапе зафиксированы:

- **PostgreSQL** - основная база данных;
- **REST API** - взаимодействие Frontend и Backend;
- **OpenAPI** - описание API-контрактов;
- **JSON / UTF-8** - формат запросов и ответов;
- **ISO 8601** - формат дат;
- переменные окружения - для API-ключей и секретов;
- `.env` не хранится в Git;
- единый формат ошибок API;
- общий тестовый набор данных для интеграции компонентов.

В обязательную версию входят:

- PostgreSQL;
- Backend/API;

В Release 0.5 не входят как обязательные функции:

- регистрация и постоянный профиль;
- сложная ML-персонализация;
- collaborative filtering;
- прогноз загруженности;
- собственная навигация;
- полный охват всей Москвы.

## Базовый пользовательский сценарий

1. Пользователь вводит исходную точку.
2. Выбирает категорию места и нужные параметры.
3. Spot4u получает подходящие места из локальной базы.
4. Применяются обязательные фильтры.
5. Для подходящих мест рассчитывается StudyScore.
6. Пользователь получает отсортированный список.
7. Те же места отображаются на карте.
8. Пользователь открывает карточку выбранного места.
9. При необходимости переходит к построению маршрута в Яндекс Картах.

## Организация разработки

Команда использует гибридный подход **Scrum + Kanban**.

- работа ведётся короткими итерациями примерно по 2 недели;
- задачи хранятся в Product Backlog;
- текущая работа отслеживается на доске;
- структура работ: Epic → Features → Tasks;
- результаты и договорённости фиксируются в «Сфере» и Git-репозитории.


## Статус проекта

Spot4u находится в активной разработке. Команда последовательно формирует данные, Backend/API, модуль фильтрации и ранжирования, интерфейс и интеграцию компонентов для Release 0.5.
